# Ultimate Collections for Lampa 🎬

Універсальний плагін для медіаплеєра **Lampa**, який об'єднує каталоги **Фільмів**, **Серіалів** та **Західної мультиплікації** в єдине зручне меню.

Всі категорії сформовані на основі запитів до TMDB зі збереженням структури, розумною фільтрацією та фолбеком на англійські назви для контенту без укр перекладу.

---

## 🌟 Особливості

* **3 каталоги в одному плагіні:**
  * 🍿 **Фільми** (Свіжачок, топові збірки за регіонами, усі жанри, десятиліття).
  * 📺 **Серіали** (Гарячі новинки, культові шоу, дорами, жанрові добірки).
  * 🎨 **Мультиплікація** (Західні мультфільми та мультсеріали з фільтрацією азійського контенту).
* **Чистий код:** Оптимізовано без дублювання функцій та зайвих запитів.
* **Автоматичний переклад:** Якщо у TMDB відсутня українська назва/опис, плагін підтягує англійські дані або оригінальну назву (без азійських ієрогліфів).
* **Авто-додавання в меню:** Плагін сам стежить за інтерфейсом Lampa і додає кнопки навігації у бічне меню.
