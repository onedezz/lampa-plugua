# Lampa Catalogs Plugins

Колекція кастомних плагінів-каталогів для медіацентру **Lampa**: фільми, серіали, мультфільми та мультсеріали з зручним сортуванням, локалізацією та фільтрацією.

## 📦 Доступні плагіни

* **`film.js`** — Каталог «Фільми»: свіжі релізи, англомовні, європейські та азійські фільми за жанрами й десятиліттями.
* **`series.js`** — Каталог «Серіали»: добірки ігрових серіалів за регіонами, жанрами та роками випуску.
* **`animation.js`** — Каталог «Мультсеріали»: західна анімація з поділом за віковими категоріями та десятиліттями без аніме.

## 📥 Встановлення в Lampa
