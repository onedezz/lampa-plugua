# 🚀 trendGO for Lampa

**trendGO** — це ультимативний, все-в-одному комбайн-плагін для медіацентру **Lampa**, створений для зручного перегляду найпопулярнішого та найактуальнішого контенту без зайвого баласту та розкиданих по меню додатків.

---

## 🌟 Особливості плагіна

* **🔥 Тренди + Популярне в одному флаконі:** Кожна категорія інтелектуально об'єднує найгарячіші новинки та масовий стійкий попит.
* **🛡️ Розумна фільтрація та цензура:** 
  * Повна відсутність небажаного контенту (автоматично відсіюються фільми та серіали з певних регіонів).
  * Чітке розмежування: західний кінематограф, анімація, аніме (Японія/Корея) та дорами без змішування в купу.
* **🇺🇦 Пріоритет української мови:** Автоматичне підтягування українських назв із TMDB із надійним англійським фолбеком (захист від нечитабельних ієрогліфів та кандзі).
* **⚡ Максимальна швидкість та оптимізація:** 
  * Легкий і швидкий стартовий завантажувач (по 20 ідеальних карток у рядку).
  * Повноцінна сітка з нескінченною пагінацією при натисканні на «Показати більше».

---

## 📂 Категорії в меню

1. **🔥 Фільми** — актуальні західні повнометражні стрічки.
2. **📺 Серіали** — популярні багатосерійні західні проєкти.
3. **🍿 Мультфільми** — повнометражна західна анімація.
4. **🎨 Мультсеріали** — популярні анімаційні серіали.
5. **⛩️ Аніме Фільми** — повнометражні аніме-картини
6. **⚔️ Аніме Серіали** — добірки японських та корейських аніме-серіалів.
7. **🎭 Дорами Фільми** — азійські фільми.
8. **🌸 Дорами Серіали** — популярні багатосерійні дорами.

---

## 📥 Встановлення у Lampa

1. Скопіюйте посилання http://onedezz.github.io/lampa-plugua/trendgo.js
2. Відкрийте медіацентр **Lampa**.
3. Перейдіть у **Налаштування** ➔ **Плагіни**.
4. Натисніть **Додати плагін** і вставте посилання.
5. Перезапустіть додаток — у головному меню з'явиться новий пункт **trendGO**.
